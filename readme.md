# XXI: System Toolkit by livingSatire

## About
XXI is a system toolkit for maintaining a Linux system. It is not a distro, but a small collection of tools to maintain your own system. 

## The Bash addict that is package building
One of the main problems with most distros is a hard dependcy on bash for build scripts. XXI insted uses POSIX scripts for building, so you can use any POSIX complient shell to build and and run a XXI based system. 

## Depenecys
### Out of system depencencys
- A fine linux system to bootstrap from
- A turning complete computer with Linux Kernel support
### XXI dependencys
- POSIX shell
- Mostly* POSIX complent userspace utils (Busybox, Toybox, GNU Utils)
- A 'tar' implmentation
